# Meow Watch : applis

Les fichiers à installer des applis Meow Watch, construits ici gratuitement à partir du code (privé) de Meow Watch.
Ce dépôt ne contient que la recette de construction (`.github/workflows/applis.yml`).

- Android (télé et téléphone) : **meowwatch.vkzdev.com/tv.apk**
- Apple TV : **meowwatch.vkzdev.com/tv.ipa** (non signé, à signer avec Signulous)
- iPhone : **meowwatch.vkzdev.com/iphone.ipa** (non signé, à signer avec Signulous)
- Windows : **meowwatch.vkzdev.com/windows.exe** (se met ensuite à jour tout seul)

Les fichiers sont aussi dans les [Releases](../../releases).
